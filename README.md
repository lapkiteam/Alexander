# Александр

## Преобразование в PDF

* Преобразовать в twee:

  ```bash
  ./convert.fsx
  ```

* Перейти на страницу [Import Game](https://gordianbook.art/load-json)
* Импортировать `Александр.twee`
* Нажать кнопку "Import"
* Перейти на страницу [Export Gamebook PDF](https://gordianbook.art/pdf)
* Сохранить документ
